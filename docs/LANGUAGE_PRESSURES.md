# MNCS language pressure ledger

Each item records workload, observed behavior, required semantic, reproducer, owner, workaround and closure verification.

## Initial pressure targets

- generic 2D/3D/N-dimensional coordinate types
- compile-time dimensions and coordinate frames
- robust/adaptive arithmetic without excessive abstraction cost
- exact integer/rational interoperability
- SIMD vectorization and AoS/SoA layout control
- graph/mesh ownership and adjacency representation
- recursive spatial structures
- nullable/optional handles and stable IDs
- deterministic sorting/reductions for geometric algorithms
- CUDA-compatible data structures
- diagnostics around numeric-type and frame mismatches
- zero-cost abstraction for geometric primitives
